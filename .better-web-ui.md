## Design Context

### Users
This presentation supports Tolu's AltSchool final project demonstration to assessors and classmates. Slides must explain the cloud delivery workflow clearly from a projector.

### Brand Personality
Clear, confident and practical. Use plain explanations backed by repository evidence.

### Aesthetic Direction
Use the Kudos Board's forest-green identity with pale neutral slides, strong dark-green section slides, large readable typography and varied layouts. Architecture and branch diagrams provide the visual signature. Screenshots remain labelled with their original dates.

### Implementation Defaults
The existing application uses plain HTML, CSS and JavaScript with Express. This task changes presentation artifacts only. Build editable 16:9 slides through the bundled Artifact Tool runtime.

### Design Principles
- Give each slide one clear focal point.
- Use scale, spacing and weight before adding decorative elements.
- Alternate diagrams, evidence and explanations to support a spoken presentation.
- Keep actual implementation distinct from proposed workflow and historical evidence.
- Preserve screenshot proportions and show evidence at a useful reading size.
